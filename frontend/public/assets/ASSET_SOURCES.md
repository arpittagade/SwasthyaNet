# Visual asset sources

The dashboard uses an unDraw medical-care illustration downloaded from the official unDraw page:

- Source page: https://undraw.co/illustration/medical-care_7m9g
- Asset: `medical-care.svg`
- Intended use: a restrained visual anchor in the outbreak intelligence panel, not a data-bearing visualization.
- Source guidance observed: unDraw describes its illustrations as open-source and provides a direct SVG download for projects. Verify the current unDraw license page before any commercial production reuse.

The application’s authoritative operational visuals remain generated from the synthetic API data and are not replaced by decorative imagery.
